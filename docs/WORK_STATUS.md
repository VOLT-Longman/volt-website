  랜딩 구조 변경은 이 문서에 선언한 뒤 진행한다 — 두 세션이 같은 화면을 다른 방향으로 밀지 않는다.

  로컬 win32 기준은 개발 편의용 참고본이며, 세션 간 서브픽셀 차이로 어긋나도 회귀로 취급하지 않는다.

  기존 원오프 breakpoint(600/640/680/860/900/1040/1100)는 해당 컴포넌트를 수정할 때만 정리한다.

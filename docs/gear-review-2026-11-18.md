# 개인 장비 검수와 캐패시터 정렬

대상: `feat/fps-gear`의 `9a85a9e`. 최신 main `01802f8`과 합쳐 검수했다. 기존 AI·실드별 전원·함선 도구 연결을 보존했다. `index.html`의 버전 태그와 `css/styles.css` 끝의 충돌은 양쪽 기능을 모두 남겼다.

## 직접 확인한 자료

- 설치 게임 `Game2.dcb`, `build_manifest.id`, 영문 `global.ini`, 설치된 한국어 패치 `global.ini`로 다시 생성했다. 게임 버전 `4.10.200.58746`, changelist `13165946`. DCB SHA-256 `005984f5507314a0d5dc3a8d7457bffc03578eeabb1e5da6e6c2d010e81649f4`를 생성물에 기록한다.
- ADP-mk4 코어 `_01`과 `_02`는 각각 −70~100°C, −80~105°C여서 합치면 안 된다. 대표 변종의 정식 이름으로 구분했다. 잘린 공통 이름을 억지로 만들지 않으며, 헬멧 묶음은 실제 헬멧 변종 이름을 우선한다. 원문 자체가 Core로 잘못 표기된 헬멧 변종 이름은 원본 그대로 변종 목록에 남긴다.
- 방어구 2,493개 전체의 무게·보호 부위를 원본과 대조했다. 기존 묶음 안 무게 차이는 없었다. 보호 부위는 이제 부위별 고정 표 대신 각 장비의 `protectedBodyParts`를 추출한다. Pembroke 변종의 반복된 부위 참조는 중복 제거한다. 마네킹 전용 정의와 PH 임시 이름을 제외해 2,489개, 488묶음이다.
- 무기도 무게를 묶음 기준에 포함했다. 405개, 62묶음. 색상 이외의 무게 차이를 가진 Cambio 변종은 분리된다. 상점 자료가 없다는 이유로 제외하지 않는다.
- P4-AR 810rpm, Coda 180rpm 상한, Custodian 자동 800rpm, Gallant 900/825rpm 발사 정의를 대조했다. Scalpel은 1.2초/2발 및 3초/2발 순서다. `Individually`는 방아쇠 한 번에 2발이라는 의미가 아니므로 해당 안내를 제거했다. 순차 연사는 대기 시간으로 산출한 주기 평균이며 게임 실측이 아니다.
- 도구에 남아 있는 기본 탄약 참조를 실제 공격력으로 표시하지 않는다. WowBlast의 `ea_elim` 정의는 별도 게임 모드 설정으로 구분한다.
- UEX 공개 `/2.0/categories` 응답에서 1 팔, 2 배낭, 3 헬멧, 4 다리, 5 몸통, 18 개인 무기, 24 언더수트를 확인했다. 서버 허용 목록은 이 7개만 추가한다. 기존 1시간 캐시·60초 새로고침 제한 유지. 화면은 분류별로 순서대로 요청한다. `fix/uex-upstream-limit`은 합치지 않았다.

## 계산의 한계

인계문과 달리 브랜치 코드는 방어구와 언더수트 감소를 곱하지 않았다. 겉 방어구가 있으면 그 한 겹을 적용하고, 없을 때 언더수트를 적용한다. 이 처리와 체력 풀을 나눈 발 수는 게임 안에서 검증하지 못했다.

착용 시험 상단에 가정과 한계를 항상 표시하고, 쓰러짐/사망을 예측한다는 표현을 제거했다. 부위 피해를 전체 체력으로 나눈 값은 단순 환산이라고 표시한다. 충전·폭발·기절·디스토션 계산은 제외한다. 시간은 일정한 자동 연사/빔만 단순 환산하며 재장전, 출혈, 관통, 방어구 내구도, 실전 생존시간은 계산하지 않는다. 게임 파일 값과 실전 검증을 구분한다.

## 이미지와 화면

- 위키 문서 연결은 redirect의 역방향 1:1 매핑을 순방향으로 수정했다. 여러 문서가 같은 문서로 연결되는 경우에도 원래 요청 이름을 잃지 않는다.
- ADP-mk4 헬멧에 몸통 그림이 붙던 연결을 수정했다. P4-AR, ADP 헬멧/코어, Odyssey 언더수트의 문서와 파일 연결을 표본 대조했다. 모든 그림을 눈으로 확인한 것은 아니다.
- 위키가 제공하는 320px 축소본을 다시 받았다. 487개 약 23.8MB이며, 없는 그림 63개는 빈자리로 둔다(문서/허용 조건 없음 60, 다운로드 실패 3). 사용하지 않는 기존 사본 8개는 제거했다. 전부 미리 받지 않고 지연 로드한다.
- 그림별 저작자·원본 외에 CC 이용 조건 링크와 축소 사본 표시를 보완했다. 선택한 색상과 다른 예시일 수 있음을 명시했다. 참고: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), [RSI 팬 콘텐츠 안내](https://support.robertsspaceindustries.com/hc/en-us/articles/360006895793-Star-Citizen-Fankit-and-Fandom-FAQ). 위키가 기재한 개별 파일 권리 정보를 따르며 독립적인 권리 보증은 아니다.
- 이름/영문 이름/변종 수를 그림 옆의 고정 영역에 배치했다. 모바일 상세에 목록 복귀를 추가했다. 최저가 외 판매처도 펼쳐서 볼 수 있다.
- 모바일 실제 조작에서 상세 그림/표가 카드 밖으로 나가는 문제를 발견해 상세 열의 최소 너비를 0으로 제한했다. 페이지 전체 너비뿐 아니라 카드 자식의 경계도 검사한다. 모바일 표의 가로 스크롤 안내를 추가했다.
- 장바구니를 먼저 연 상태에서 가격이 늦게 도착해도 합계가 갱신된다. 착용 자료 실패 시 다시 시도할 수 있고, 잘못 저장된 수량은 제외한다.
- 캐패시터는 채널마다 같은 바닥선에서 위로 쌓인다. 최소 전력 장비 버튼은 유지하고 추가 칸은 빈 공간을 채우려고 늘어나지 않는다. 320px에서 두 줄로 바뀌는 숫자 조절부도 높이를 확보한다.

## 보안과 공개 상태

`gear.js`의 HTML 삽입은 기존 단일 draw 지점만 사용하며 동적 텍스트·속성을 escape한다. 원본/이용 조건 링크는 허용된 HTTPS 도메인만 표시한다. 악성 이름 회귀 검사를 유지한다. 기존 공개 상태를 바꾸지 않았다. 도구를 다시 잠글 때 개인 장비를 포함할지는 별도 운영 결정으로 남는다. 이번 변경은 인증/권한/AI 제한을 변경하지 않는다.

실물 휴대폰과 게임 내 사격 실험은 확인하지 못했다. 브라우저의 모바일 크기 조작과 자동 검사는 별도로 수행한다.

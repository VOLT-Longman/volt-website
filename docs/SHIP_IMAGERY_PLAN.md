# 함선DB 공식 대표 이미지 시스템

2026-10-18: 최초 5종 시범 구현. C1 Spirit, C2 Hercules, Cutlass Black, Freelancer, Hull A의 RSI 공식 제품 페이지 Product JSON-LD와 원본 장면을 직접 대조했다. 공식 제품 홍보 사진이며 최신 게임 외형의 실시간 보증은 아니다.

## 데이터와 배포

- `data/ship-imagery.json`이 검수 목록의 유일한 원본이다. 함선 UI 고유 ID로만 연결하며 Erkul 제원 갱신과 분리한다. 도색형·한정판·파생형에 기본 선체 사진을 자동 상속하지 않는다.
- 각 레코드에 제품명, 공식 제품·원본 URL, 원본 크기와 SHA-256, 검수일과 상태, KO/EN 대체 문구, 두 로컬 파일의 크기·해상도·해시를 기록한다.
- 원본을 확대하지 않고 WebP 640px 카드 / 1280px 상세 사진으로 변환한다. 브라우저는 외부 RSI 이미지 서버에 의존하지 않는다.
- `node scripts/build-ship-imagery.mjs`로 작은 정적 `js/ship-imagery.js`를 생성한다. `--verify` 검사는 CI의 필수 check에 포함되며 ID·제품명·공식 도메인·정확한 제품 경로·중복·로컬 경로·파일 해시와 생성물 일치를 확인한다.
- 카드는 지연 로드한다. 상세에서는 이미지 출처 링크와 저작권을 작게 제공한다. 미등록·오류 사진은 빈 이미지 대신 기존 텍스트 카드와 제원 화면으로 돌아간다. 사진 모듈 실패도 검색·제원을 막지 않는다.

## 확대 절차

1. 공식 제품 페이지에서 제품명·제조사·고유 ID와 실제 장면을 확인한다. 특히 C2/M2/A2, 기본형/화물형, 도색과 한정판을 구분한다.
2. 원본 URL·해시·크기를 기록하고 썸네일/상세 파일을 생성한 뒤 검수 상태를 확정한다.
3. 생성기와 필수 검사, 오류 복구·다국어·모바일·시각 검사를 통과한 다음 배포한다.
4. 공식 원본이 바뀌면 자동 덮어쓰지 않고 재검수한다. 기존 파일과 매핑은 Git에서 복구한다.
5. 나머지 함선은 검수될 때까지 기존 텍스트를 유지한다. CMS 편집 기능과 전체 함선 사진 수집은 아직 구현하지 않았다.

소개·가입 안내의 사진 아래 반복 문구는 제거했다. 푸터의 공식 출처·저작권·비공식 팬 사이트 안내는 유지한다.

## 적용 순서와 조건

1. 판매처 오연결: UEX 품목 ID·UUID·이름을 함께 보존하고 명시적인 충돌 사례를 검토한다.
   단순 이름 포함 검사만으로 V/V-G, EM/IR 같은 구별을 통과시키지 않는다.
   게임 이름이 비어 있는 Hofstede는 이름이 다른 사례와 분리한다.
2. S0 Helix: 기본 장착 여부와 별개로 추출 대상에 포함하고 포트 규격·태그 검증 후 노출한다.
3. 레이더·관통·탄퍼짐·비행·전력: 원본 값과 출처부터 표시한다.
   전력 구간 계수가 어느 성능에 곱해지는지는 확인 전 자동 계산에 사용하지 않는다.
4. 항속: 현 빌드의 탱크와 소모량에 따른 약 61 Gm을 유지한다.
   상대 계산기의 입력값을 확인하지 않은 상태에서 차이 원인을 하나로 확정하지 않는다.
5. C788 연사 선택, 탐지 거리, 장갑 판정, 격파 시간, 전력 부족 시 차단 순서는
   자료에서 확정하지 못한 실행 규칙을 확인한 뒤 구현한다.

큰 원본 JSON은 화면 진입 때 일괄 내려받지 않는다. 실제 기능에 필요한 표시용 필드만
빌드 단계에서 추려 기존 자료와 게임 빌드가 일치하는지 확인한 뒤 싣는다.

# 화면 용어 기준

게임에서 익숙한 표현과 뜻이 바로 드러나는 한국어를 사용한다. 분류와 안내 문구만 다듬고, 게임 한국어 패치의 장비·함선 고유명사, 데이터 식별자, 계산식은 바꾸지 않는다.

| 이전 표현 | 화면 표현 |
| --- | --- |
| 경장갑 / 중장갑 / 중(重)장갑 | 라이트 아머 / 미디움 아머 / 헤비 아머 |
| 방어구 등급 | 아머 종류 |
| 소총 / 산탄총 / 저격소총 / 발사기 분류 | 라이플 / 샷건 / 스나이퍼 / 런처 |
| 변종 | 스킨·버전 |
| 착용 시험 | 착용·피해 테스트 |
| 피해/발 / 연사(분당) | 한 발 피해 / 분당 발사 수 |
| 축전 탄창 | 에너지 탄창 |
| 정격 기준 | 부품 기본 수치 기준 |
| 항속 거리 | 최대 이동 거리 |
| 규모·플랫폼 / 대분류 | 크기·종류 / 활동 종류 |

목록, 필터, 상세 화면, 세트 선택, 장바구니에서 같은 표현을 쓴다. DPS·캐패시터처럼 익숙한 용어는 유지하고 설명에서 뜻을 풀어 쓴다. 가정 계산·확인되지 않은 효과·가격 자료의 한계는 표현을 쉽게 바꾸더라도 생략하지 않는다. 원본 장비 이름에 포함된 ‘소총’ 등은 분류명을 바꾸더라도 유지한다.

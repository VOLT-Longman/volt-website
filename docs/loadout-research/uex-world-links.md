# 게임 자료와 UEX 대조·연결 (2026-11-18)

`scripts/loadout-research/uex-link.mjs` 가 게임 원본에서 뽑은 자료와 UEX 공개 API(`https://api.uexcorp.uk/2.0`) 응답을 대조해 `data/loadout-research/uex-world-links.json` 을 만든다.
UEX 응답 원본은 저장소에 넣지 않았다. 사이트 코드와 `data/loadout/` 는 건드리지 않았다.

연결 규칙: 고유번호(UUID)가 같으면 `verified`, 이름만 같으면 `name`, 여러 개가 걸리면 `ambiguous`, 없으면 `none`. `name` 은 사람이 확인하기 전에는 확정이 아니다.

## 읽을 때 주의

- **상품**: UEX 상품에는 UUID 가 없어 이름으로만 이었다. 게임에만 있는 40개는 전력·산소·열 같은 내부 자원, 자리표시, 이번 판에 새로 들어온 품목(예: Lastaprene, 배 탄약 S8·S9)이다. UEX에만 있는 38개는 행사 품목, 아직 게임 자료에 없는 품목, 표기가 다른 것(Lastaphrene ↔ Lastaprene, Caranite ↔ Carinite, Ice (Raw) ↔ Raw Ice)이다. 표기 차이는 손으로 이어야 한다.
- **채광 장소**: 스탠튼·파이로의 행성과 위성 25곳은 천체 이름으로 이어졌다(예: `HPP_Pyro2` = Monox). 나머지는 천체가 아니라 지역(아론 헤일로, 라그랑주 A~G, 닉스 고리 등)이라 UEX 천체 목록에 짝이 없다.
- **함선 적재량**: 159척 가운데 140척은 게임 화물칸 합과 UEX 값이 같다. 다른 19척은 대부분 게임 쪽이 0으로 나온 것으로, 화물칸이 기본 장착 목록이 아닌 다른 곳(모듈, 내부 구획)에 달려 있어 이 스크립트가 못 찾은 것이다. 게임 값이 틀렸다는 뜻이 아니다. 890 Jump(388 ↔ 100), Starlancer MAX(224 ↔ 96), Valkyrie Liberator(30 ↔ 90)는 따로 볼 것.
- **UUID 로 못 찾은 125척**: C2 Hercules 처럼 실제로 있는 함선도 포함된다. UEX 쪽 UUID 가 비었거나 다른 정의를 가리킨다. 이름 대조를 추가해야 한다.
- **거점**: 관문 정거장은 양쪽 성계에 같은 이름이 있어 여러 개가 걸린다.
- 가격은 UEX 값을 그대로 붙였을 뿐, 게임 파일과 대조할 대상이 없다(게임 파일에 가격이 없다).

## 다음에 할 것

1. 상품 표기 차이 손 대응표.
2. 함선 이름 대조와, 화물칸을 못 찾은 19척의 구조 확인.
3. 광물 → 정제 후 상품 → UEX 시세 → 그 상품을 쓰는 설계도까지 한 줄로 잇기.
4. 채광 지역(라그랑주 등)에 사람이 읽을 이름 붙이기.

# 2차 (2026-11-18 추가)

## 바뀐 수치

| 대상 | 1차 | 2차 |
| --- | --- | --- |
| 상품 | 이름 일치 167 | 이름 167 + 손 대응 6 = 173 (게임에만 34, UEX에만 32) |
| 함선 | UUID 일치 159 | UUID 159 + 이름 62 = 221 (SCU 같음 182, 다름 39). 못 찾음 63 가운데 44는 UEX가 컨셉으로 표시한 함선 |

손 대응 6건(게임 id → UEX 이름): `Raw_Ice` → Ice (Raw), `RawSilicon` → Silicon (Raw), `RawOuratite` → Ouratite (Raw), `Lastaprene` → Lastaphrene, `ConstructionMaterialPowder` → Construction Material Rubble, `ConstructionMaterialChunks` → Construction Material Salvage. 낱말 순서나 철자만 다르다고 판단한 것이며, 게임 안에서 같은 물건인지 확인하지는 않았다.

함선 이름 대조: 게임 쪽 영어 함선 이름(`vehicleName`)과 UEX 이름이 같을 때 잇는다. 같은 이름의 정의가 여럿이면 클래스명이 가장 짧은 기본형만 고른다.

SCU가 다른 39척은 두 부류다. (1) 게임 쪽이 0이거나 작게 나온 것: 화물칸이 함선의 기본 장착 목록이 아닌 곳에 달려 있어 못 찾음(Aurora, Constellation, Mustang, Nomad 등). (2) 실제 차이로 보이는 것: A2 Hercules(UEX 234 ↔ 게임 216), 600i Executive(40 ↔ 44), 890 Jump, Starlancer MAX, Valkyrie Liberator. (2)는 어느 쪽이 맞는지 게임 안 확인이 필요하다.

아직 못 찾은 비컨셉 함선 19척: 한정판 도색(Best In Show 등), Retaliator 모듈, ATLS 등. UEX는 이것들을 별도 항목으로 두지만 게임에서는 기본형과 같은 정의이거나 함선이 아니다.

## 광물 한 줄 연결 (`resource-chain.json`)

`scripts/loadout-research/resource-chain.mjs` 가 "장소 → 암석 → 광물 → 정제 상품 → UEX 시세 → 그 상품을 쓰는 설계도"를 잇는다.

- 원광 33종, 그중 정제 상품이 있는 것 26종, 설계도에 쓰이는 것 26종. 설계도 재료 가운데 채광으로 얻을 수 없는 것은 없었다.
- 연결 고리: 채집 목록 항목 → 암석 엔티티의 `MineableParams.composition` → 구성의 광물 → 광물의 `resourceType`(원광) → `refinedVersion`(정제 상품).
- 예: 퀀타늄 원석 → Quantanium, UEX 판매 시세 148,409, 설계도 3개. 스틸러론 → 137,818, 설계도 141개, 파이로 쪽. 오라타이트 → 45,677, 설계도 506개, 허스턴과 그 위성.
- `places.score`(암석 비중 × 포함 확률 × 최대 함량)는 장소끼리 견주는 참고값이다. 실제 수율이 아니다.
- 손 채광·지상 차량 채광 광물 7종(하다나이트, 야날라이트 등)은 정제 상품이 없고 원석 그대로 판다.

## 남은 것

- UEX 시세 숫자의 단위(SCU당인지)를 UEX 문서로 확인.
- SCU가 다른 함선의 화물칸 위치 확인.
- 한글 이름.
- 운송 계약의 상품·출발지·도착지를 UEX 거점과 잇는 작업.

# 3차: 수치가 다르면 게임 파일을 따른다 (2026-11-18)

소유자 결정: 게임 파일과 UEX의 수치가 다르면 게임 파일 값을 따른다. 가격·재고처럼 게임 파일에 없는 것만 UEX를 쓴다.

이 규칙을 적용하려면 "게임 값"이 실제로 읽은 값이어야 한다. 그래서 먼저 화물칸 찾기를 고쳤다. 화물칸이 화물 선반·승강기 같은 중간 부품의 기본 장착 안에 들어 있는 경우까지 따라간다. 개인 보관함(무기고)은 적재량에서 빼고 따로 센다.

| 구분 | 수 | 뜻 |
| --- | --- | --- |
| `same` | 207척 | 게임과 UEX가 같다 |
| `game` | 7척 | 다르다. 게임 값을 채택 (`adoptedScu`) |
| `unread` | 7척 | 게임 쪽 화물칸을 하나도 읽지 못했다. 0은 게임 값이 아니라 추출 누락이라 아직 정하지 않았다 |

게임 값을 채택한 7척:

| 함선 | UEX | 게임(채택) |
| --- | --- | --- |
| 600i Executive Edition | 40 | 44 |
| 890 Jump | 388 | 100 |
| A2 Hercules | 234 | 216 |
| Hammerhead | 40 | 64 |
| MULE | 2 | 1 |
| Valkyrie Liberator Edition | 30 | 90 |
| Aurora Mk II | 0 | 2 |

읽지 못한 7척: 135c, F7C Hornet Mk II, Nomad, Retaliator, Retaliator Bomber, Golem, Prowler Utility. 화물칸이 문·화물 구역·모듈·채광 포드 안쪽에 있어 지금 방식으로는 닿지 않는다. Golem 의 32는 화물이 아니라 광석 포드 용량일 가능성이 높다.

주의: 890 Jump 는 격납고 화물칸 6개(합 100)만 읽혔다. UEX의 388과 차이가 커서, 읽지 못한 화물칸이 더 있는지 한 번 더 볼 가치가 있다. 규칙대로 지금은 게임 값 100을 채택으로 표시해 두었다.

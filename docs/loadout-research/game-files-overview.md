## 게임 파일에 없는 것

- 상점 가격과 재고. 품목의 표시 이름만 있고 값은 서버가 준다. UEX가 계속 필요하다.
- 보험 청구 시간·비용. 해당 구조체를 찾지 못했다.
- 천체 표면의 좌표별 분포(광물이 몰린 지역 등).
- 지도 좌표·거리는 이번에 확인하지 않았다(`StarMapObject`에 위치 값이 있는지 추가 확인 필요).

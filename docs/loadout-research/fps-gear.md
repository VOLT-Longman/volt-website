## 주의

- **연사 속도는 원본의 `fireRate` 값이다.** 볼트액션 저격총·쌍열 산탄총처럼 한 발 뒤 동작 시간이 있는 무기는 실제 연사가 이보다 느리다(Ravager-212 원본 800 / UEX 105, Scalpel 600 / 50). 함선 무기에서 본 것과 같은 문제다. 이 항목은 "게임 값 채택"으로 표시했지만 실제 연사로 쓰려면 발사 순서·대기 시간을 더 읽어야 한다.
- 조준경 배율은 대조에서 뺐다. 원본의 `zoomScale` 이 제품 이름의 배율과 같은 값인지 확인하지 못했다(FarSight 8x 의 원본 값 4).
- 이름으로만 이은 796건은 사람이 확인하기 전에는 확정이 아니다.
- 못 찾은 UEX 품목 196건은 대부분 UEX 에 고유번호가 없고 이름 표기가 다른 것이다.
- 한글 이름, 소모품(의료·수류탄) 효과, 의류는 아직 하지 않았다.
- 게임 안에서 실측한 값은 없다.

# 보완: 실제 연사와 한글 이름 (2026-11-18 추가)

## 실제 연사

순차 발사(`SWeaponActionSequenceParams`) 무기 9가지(변형 포함 43종)는 항목마다 적힌 "다음 항목까지의 대기"(초 또는 분당 횟수)로 한 바퀴 시간을 구해 실제 연사를 계산했다. `fps-weapons.json` 의 `modes[]` 에 `cycleSeconds`, `shotsPerCycle`, `cyclesPerMinute`, `rpmEffective` 를 실었다. 계산값이 안쪽 `fireRate` 한도보다 크면 한도를 따른다.

| 무기 | 원본 fireRate | 계산한 값 | UEX |
| --- | --- | --- | --- |
| 스칼펠 저격소총 (자동 순차) | 600 | 한 번 당겨 2발, 분당 50회 당김 | 50 → 지금 300 으로 표기 |
| 라바저-212 트윈 산탄총 | 800 | 분당 350발 (한 바퀴 2발, 분당 175바퀴) | 105 |
| R97 산탄총 | 455 | 분당 375발 | 120 |
| 루민 V 기관단총 | 700 | 분당 625회 점사 | 562.5 |

UEX 와 견줄 때는 한 번 당겨 여러 발이 나가는 무기를 "당김 횟수"로 맞췄다.

연사 값의 믿을 만한 정도를 `differences[].basis` 에 적었다.

| basis | 뜻 | 다른 건수 |
| --- | --- | --- |
| `sequence` | 발사 순서의 대기 시간으로 계산한 값 | 아래 실행 결과 참고 |
| `automatic` | 연사·점사 무기의 원본 값. 그대로 써도 된다 | |
| `upperBound` | 단발·충전식의 원본 값. 장전 동작과 충전 시간이 원본 값에 들어 있지 않아 실제는 더 느릴 수 있다 | |

`upperBound` 인 무기(P6-LR 55, 붐튜브 500, 제니스 325 등)는 규칙대로 게임 값을 채택으로 표시했지만 "최대 한도"로 읽어야 한다. 실제 연사는 애니메이션 길이에 달려 있어 게임 파일의 수치만으로는 구하지 못했다.

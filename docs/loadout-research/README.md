- 게임 빌드: 4.10.0 (`4.10.200.58746`, 변경 번호 13165946, 2026-11-11 빌드)

모든 파일은 부품·함선을 **`uuid`(게임 레코드 GUID)와 `cls`(클래스명)** 로 가리킵니다. `name` 은 표시용입니다.

## 값의 상태 표기

- `verified` — 원본 값과 계산이 한 가지로 정해짐.
- `conflicting` — 자료끼리 또는 해석끼리 어긋남. 값을 둘 이상 나란히 실었습니다.
- `unavailable` — 이 자료만으로는 확정할 수 없음. `null` 로 두고 필요한 후속 자료를 적었습니다.

`null` 은 "확인하지 못한 값"에만 씁니다. 원본에 아예 없는 칸은 싣지 않았고, 누락을 0 으로 채우지 않았습니다.

## 하지 않은 것

- **다른 DPS 계산기 화면을 직접 열어 수치를 대조하지 않았습니다.** 이 저장소의 기존 원칙(해당 사이트의 자료·코드를 가져오지 않는다)에 따라, 지시문에 적힌 비교 수치(항속 61 Gm 대 120 Gm 등)만 입력으로 썼습니다. 그래서 "차이의 원인"은 원본 값에서 나올 수 있는 후보를 계산으로 좁힌 것이고, 상대 쪽 입력값으로 확정한 것은 아닙니다.
- 게임 안에서 직접 재 보는 실측은 하지 않았습니다. 실측이 필요한 항목은 각 문서에 표시했습니다.
- 게임 원본 파일과 UEX 원본 응답은 커밋하지 않았습니다.

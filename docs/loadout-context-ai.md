# VOLT AI 구성 검토 — 20261118-13

로드아웃·함선 DB·무역플래너에서 선택한 함선을 AI에 가져와 같은 맥락에서 검토한다. 로드아웃에서는 장착·전원·배정·A/B 정보를, DB에서는 함선 ID를, 플래너에서는 함선 ID와 사용자가 입력한 SCU를 전달한다. 화면 이동 자체는 질문을 전송하지 않는다.

## 계산과 답변

- `functions/_shared/ai-loadout.js`는 클라이언트 성능 값과 임의 지시를 받지 않는다. 길이·형식·개수를 제한한 선택 정보만 검증한다.
- 같은 배포의 게임 파일 `meta/index/items/comparison/availability/ko/ships`와 `js/loadout-calc.js`를 사용한다. 서로 다른 게임 버전은 합치지 않으며 출시된 함선을 유일하게 찾지 못하면 자료 없음으로 답한다.
- 서버에서 호환 장착, 전원, 배정량을 다시 검증하고 화력·실드·최대 소비·EM·항속을 계산한다. 비교 구성은 전달된 반대 A/B이며 없으면 기본 구성이다.
- 확인할 점에는 정격 최대 소비 대비 출력, 실드별 전원, 최소 배정 누락, A/B 차이, 계산 한계를 표시한다. 플래너 SCU는 사용자 입력이지 검증된 화물칸 용량이 아니라고 명시한다.
- 결과와 비교표는 서버에서 확정한다. 기존 Cloudflare 모델은 선택적 짧은 해설만 더하며 새 수치의 근거가 되지 않는다. 로그인, 분당/일/월 한도, 모델·비용 설정은 변경하지 않는다.
- 미검증 부분 전력 성능, 채광 모듈 중첩, 교전 생존시간이나 최적 장비를 추정하지 않는다. 가격·재고는 이 검토에서 정적으로 보증하지 않고 무역플래너에서 갱신하도록 안내한다.

## 상태와 이동

선택 정보만 탭의 sessionStorage에 저장하여 로그인 왕복 시 유지한다. 대화는 기존처럼 새로고침 시 초기화한다. 새 대화/선택 해제로 선택 정보를 지울 수 있다. 로드아웃을 나중에 편집했다면 AI 버튼을 다시 눌러 최신 구성을 가져와야 한다. 결과의 복귀 버튼은 같은 함선의 편집 상태를 보존한다.

## 검증

백엔드 검사는 실제 저장소 게임 파일로 Titan 한쪽 실드 OFF(2,160 HP)와 두 실드 ON(4,320 HP), 위조 입력 배제, 버전 불일치, 출시 함선 대응, 인증 유지, 영어 운송 입력 구분을 확인한다. 화면 검사는 1440/390px에서 개별 전원·A/B·AI 검토·복귀·새로고침·접근성, DB/플래너 선택 전달, 전력 부족 안내와 실행 취소를 확인한다. 모델의 임의 질문 전체에 대한 정확도나 게임 안 실전 검증을 뜻하지 않는다.

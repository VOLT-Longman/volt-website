# CMS 관리자 계정과 테스트 환경

## 관리자 로그인

- 운영 CMS의 Discord 로그인은 `ADMIN_DISCORD_ROLES=["대표이사","임원진"]`에 허용된 역할만 받는다. 감찰과 일반 함대원은 허용하지 않는다.
- 기존 Discord OAuth 범위를 그대로 사용한다. CMS 로그인 버튼은 별도 관리자 쿠키를 만들며, 일반 홈페이지 로그인만으로 CMS에 접근할 수는 없다.
- 계정과 관리자 쿠키가 같은 세션인지 확인하고, Discord 서버 역할은 최대 60초 간격으로 재검증한다. 검증 실패 시 편집을 허용하지 않는다.
- CMS 로그아웃은 관리자 쿠키만 지운다. Discord 계정 로그아웃 또는 서버 측 세션 폐기는 해당 계정의 CMS 접근도 막는다.
- 기존 공통 관리자 비밀번호는 호환성을 위해 유지한다. 0016 적용 후 새 변경 이력에는 Discord 계정의 표시 이름·계정 ID·로그인 방식을 기록한다. 공통 비밀번호는 개인 신원을 확인할 수 없어 공통 관리자로 표시한다.

## Cloudflare Pages 미리 보기

미리 보기 환경은 운영과 별개 리소스를 사용한다. 운영 데이터를 복사하거나 운영 비밀을 재사용하지 않는다.

| 설정 | 미리 보기 값 |
| --- | --- |
| `DB` | D1 `volt-cms-preview` (`3640529b-5c9a-41bb-9f67-cf341074dda9`) |
| `GALLERY_BUCKET` | R2 `volt-gallery-preview` |
| `R2_PUBLIC_BASE_URL` | `https://pub-28f4a23bdc45459f930c05c466940833.r2.dev` |
| `VOLT_ENVIRONMENT` | `preview` |
| `ADMIN_PASSWORD` | 테스트 전용 비밀, 사용자 직접 설정 |
| `ADMIN_SESSION_SECRET` | 운영과 다른 무작위 비밀, 사용자 직접 설정 |

새 D1에는 저장소의 마이그레이션 0001~0015와 공개 기본 콘텐츠만 적용했다. 개인 세션과 운영 편집 데이터는 복사하지 않았다. 테스트용 R2 공개 개발 주소에는 공개 가능한 테스트 이미지만 올린다.

미리 보기 CMS에는 테스트 환경 문구가 표시된다. Discord OAuth, 웹훅, AI 서비스의 운영 비밀은 연결하지 않으며, 테스트 전용 공통 비밀번호로 CMS를 검증한다. 미리 보기에는 Cloudflare의 기본 검색 제외 헤더가 적용된다.

`preview` 브랜치를 업데이트하면 테스트 배포를 만들 수 있다. 운영 배포는 `main`에서 GitHub 검증 성공 후 진행한다. 운영과 미리 보기의 바인딩은 Pages 설정에서 각각 확인한다.

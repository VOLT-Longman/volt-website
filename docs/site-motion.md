# 공통 모션

VOLT의 색상과 화면 구조를 유지하면서 클릭 결과와 화면 진입을 알아보기 쉽게 한다.
추가 라이브러리 없이 `css/motion.css`와 선택적 모듈 `js/motion.js`를 사용한다.

- 제목은 480ms, 카드 진입은 480ms에 최대 200ms의 순차 지연을 적용한다.
- 메뉴는 220ms, 검색·공통 모달은 180–280ms에 표시한다.
- 버튼의 짧은 눌림과 카드의 3px 호버 이동은 마우스 환경에만 적용한다.
- 로드아웃 교체창은 처음 열 때 260ms, 탭 변경은 180ms에 표시한다.
  검색어 입력 등 동일 창의 다시 그리기에는 진입 효과를 반복하지 않는다.
- 같은 함선에서 부품 교체로 바뀐 요약 수치는 480ms 동안 강조한다.
  실제 계산값을 중간 숫자로 바꾸는 카운트업은 하지 않는다.
- 섹션 전체에는 transform을 적용하지 않는다. 고정 모달의 좌표 기준을 유지한다.

## 접근성·성능

`prefers-reduced-motion`을 처음부터 존중하고, 실행 중 변경하면 진행 중인
JS 애니메이션도 취소한다. 숨겨진 탭에서는 새 JS 애니메이션을 시작하지 않는다.
스크롤 이동도 동작 줄이기 설정을 따른다. 콘텐츠를 숨기는 준비 상태는
관찰자를 연결한 요소에만 적용하여 모션 모듈이 로드되지 않아도 읽고 조작할 수 있다.

별도의 애니메이션 반복 루프, 전역 MutationObserver, 스크롤 감시자는 추가하지 않는다.
기존 IntersectionObserver를 재사용하며 클릭·포커스·화면 상태를 지연시키지 않는다.

## 확인

`tests/smoke/motion.spec.js`에서 실제 검색·닫기·교체·터치 메뉴·동작 줄이기 전환을 확인한다.
검색 창의 Esc 닫기는 기존 검색 모듈의 닫기 버튼과 같은 경로를 사용한다.
기존 랜딩·메뉴·모바일 레이아웃·로드아웃 검사도 함께 실행한다.

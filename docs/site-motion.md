# 공통 모션

VOLT의 기존 색상·화면 배치를 유지하면서 첫 방문과 조작 결과를 더 뚜렷하게 보여 준다.
`css/motion.css`와 `js/motion.js`는 공통 전환을, `js/cinematic-motion.js`는 홈의 GSAP 연출을 담당한다.

## 홈 시퀀스

- 첫 화면 사진이 1.22배에서 원래 크기로 2초 동안 정착한다.
- 큰 제목 두 줄이 160ms 간격으로 아래에서 드러난다. 데스크톱 이동은 80px, 모바일은 42px다.
- 함대명 → 제목 → 소개 문구 → 버튼 → 공지·핵심 지표가 한 시퀀스로 등장한다.
- 스크롤하면 사진만 최대 10% 이동·20% 확대되어 글자와 깊이 차이를 만든다.
  모바일에서는 사진 이동 ±2%·확대 6%로 줄인다. 글자의 불투명도나 스크롤 속도는 바꾸지 않는다.
- 아래 서비스 카드의 사진은 1.14배에서 정착한다. 가입 안내 사진도 스크롤에 맞춰 서서히 이동한다.
- 첫 화면 진입은 방문 중 한 번만 재생한다. 다른 화면에서 돌아오면 즉시 읽고 조작할 수 있다.
- 사진을 추가 다운로드하거나 동영상·3D·상시 반복 효과를 사용하지 않는다.

## 공통 화면과 로드아웃

- 기존 제목·카드·메뉴·모달의 진입, 버튼 누름과 카드 호버 효과를 유지한다.
- 함선 목록을 처음 열거나 다시 펼칠 때 앞의 8개 카드가 35ms 간격으로 등장한다.
  검색·필터로 목록을 다시 그릴 때는 반복하지 않는다. 카드 높이나 목록 배치는 바꾸지 않는다.
- 부품 교체창은 열 때만 데스크톱 오른쪽·모바일 아래에서 등장한다.
- 함선을 고르면 함선 정보와 수치가 차례로 나타난다.
- 부품 교체로 달라진 행과 수치를 700–1100ms 강조한다. 실제 숫자를 중간 값으로 바꾸지 않으며 경고 색상도 유지한다.
- 섹션 전체를 변형하지 않아 고정 모달·드로어의 좌표와 터치 영역을 유지한다.

## 접근성·성능·보안

- `prefers-reduced-motion` 초기 설정과 실행 중 변경을 모두 따른다.
  GSAP 컨텍스트를 되돌려 움직임·임시 스타일·스크롤 감시자를 함께 정리한다.
- 홈에서 나가거나 탭이 숨겨지면 홈 연출을 해제한다. 다시 돌아올 때 감시자가 중복되지 않는다.
- 홈 진입 연출은 숨겨진 탭에서 뒤늦게 재생하지 않는다.
- GSAP 또는 선택적 모듈을 받지 못하면 원래 CSS 진입과 읽을 수 있는 정적 화면을 유지한다.
- 자체 호스팅 파일과 CSSOM을 사용한다. 기존 CSP를 완화하거나 외부 CDN을 허용하지 않는다.
- GSAP 3.15.1과 ScrollTrigger는 npm의 고정 버전에서 `npm run motion:vendor`로 복사한다.
  원본 라이선스 헤더를 보존하고 `npm run check`에서 배포 파일이 설치 패키지와 일치하는지 검사한다.

## 확인

`tests/smoke/motion.spec.js`에서 검색·닫기·부품 교체·함선 변경·스크롤·화면 왕복·언어 변경,
모바일 가로 넘침, 동작 줄이기 전환, 모듈 누락과 엄격한 CSP를 검사한다.
랜딩·이미지 성능·로드아웃·접근성 검사를 함께 실행한다.
정지 화면 회귀 검사는 실제 동작 줄이기 설정으로 JS 애니메이션도 멈춘 뒤 비교한다.
실제 휴대폰의 프레임 속도·발열은 측정하지 않았다.

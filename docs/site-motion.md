# 공통 모션

VOLT의 색상과 화면 구조를 유지하면서 클릭 결과와 화면 진입을 알아보기 쉽게 한다.
추가 라이브러리 없이 `css/motion.css`와 선택적 모듈 `js/motion.js`를 사용한다.

- 첫 화면은 함선 사진이 1.16배에서 원래 크기로 1.8초 동안 정착한다.
  제목은 64px 이동과 짧은 흐림으로, 설명·버튼·공지 순서로 등장한다.
  모바일 제목은 48px 이동만 적용하여 흐림 처리 비용을 줄인다.
- 제목은 850ms·40px, 카드 진입은 850ms·56px에 최대 360ms의 순차 지연을 적용한다.
  제목 아래 강조선과 랜딩 카드 상단 선은 진입 중 나타났다가 사라진다.
  카드 자체는 축소하지 않아 등장 중에도 내부 버튼의 터치 영역을 유지한다.
- 메뉴는 420ms, 검색·공통 모달은 560ms에 표시한다. 모바일 메뉴 항목도 순서대로 나타난다.
- 버튼을 누르면 6% 줄어든다. 마우스를 올리면 버튼은 4px, 카드는 8px 떠오른다.
- 로드아웃 교체창은 처음 열 때 560ms, 탭 변경은 460ms에 표시한다.
  데스크톱은 오른쪽에서, 모바일은 아래에서 들어온다.
  검색어 입력 등 동일 창의 다시 그리기에는 진입 효과를 반복하지 않는다.
- 함선 선택 시 함선 정보와 핵심 수치가 차례로 나타난다.
- 같은 함선에서 부품 교체로 바뀐 행과 요약 수치는 700–1100ms 동안 강조한다.
  부품 행의 배경·왼쪽 강조선과 숫자의 크기 변화로 교체 결과를 알린다.
  경고 수치의 원래 색상은 유지한다.
  실제 계산값을 중간 숫자로 바꾸는 카운트업은 하지 않는다.
- 섹션 전체에는 transform을 적용하지 않는다. 고정 모달의 좌표 기준을 유지한다.

## 접근성·성능

`prefers-reduced-motion`을 처음부터 존중하고, 실행 중 변경하면 진행 중인
JS 애니메이션도 취소한다. 숨겨진 탭에서는 새 JS 애니메이션을 시작하지 않는다.
스크롤 이동도 동작 줄이기 설정을 따른다. 콘텐츠를 숨기는 준비 상태는
관찰자를 연결한 요소에만 적용하여 모션 모듈이 로드되지 않아도 읽고 조작할 수 있다.

별도의 애니메이션 반복 루프, 전역 MutationObserver, 스크롤 감시자는 추가하지 않는다.
기존 IntersectionObserver를 재사용하며 클릭·포커스·화면 상태를 지연시키지 않는다.
큰 움직임은 진입과 조작 순간에 한 번만 재생하고 원래 배치로 돌아간다.
로드아웃을 다시 그릴 때 제거된 DOM의 애니메이션은 즉시 취소한다.

## 확인

`tests/smoke/motion.spec.js`에서 실제 검색·닫기·교체·터치 메뉴·동작 줄이기 전환을 확인한다.
검색 창의 Esc 닫기는 기존 검색 모듈의 닫기 버튼과 같은 경로를 사용한다.
기존 랜딩·메뉴·모바일 레이아웃·로드아웃 검사도 함께 실행한다.
접근성의 색상 대비는 CSS·Web Animations의 유한한 진입 효과가 끝난 후 검사한다.
기존 대비 기준과 위반 허용 목록은 완화하지 않는다.

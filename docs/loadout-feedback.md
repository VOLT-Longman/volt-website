## 전력·시그니처·함선 판매처 재배치 (`20261118-12`)

- 파워플랜트 출력·쿨러 냉각량·최대 소비 전력·출력 여유/부족을 전력 분배 카드의 작은 요약으로 합쳤다. 배정 계획과 정격 성능을 구분하는 기존 안내를 유지한다. 별도의 파워·쿨러·시그니처 카드는 제거했다.
- EM/IR 시그니처와 기본 구성 대비 변화량은 선체·장갑 카드 아래로 옮겼다. 기존 장갑 시그니처 배율과 함께 볼 수 있으며, 부품 교체·전원·실행 취소 계산은 변경하지 않는다.
- 함선 판매처는 수용하되 전력·구성 작업 아래에 모두 쌓는 배치는 쓰지 않았다. 실제 데스크톱 검수에서 오른쪽 열만 길어져, 비행·퀀텀 아래의 빈 공간으로 옮겼다. 가장 저렴한 판매처 하나를 우선 표시하고 나머지는 펼쳐 보도록 구성했다. 휴대폰에서는 한 열로 이어진다. 함선은 부품 장바구니의 품목 모델과 다르므로 이번 변경에서 장바구니에 섞지 않는다.
- 기존 함선 DB의 Erkul 기반 판매처를 재사용하지 않는다. 새 `/api/uex/ship-prices`는 UEX `vehicles`, `vehicles_purchases_prices_all`, `terminals`만 조회하고 판매처·가격·식별 정보만 내려준다. 게임 성능값에는 쓰지 않는다. 전체 판매표의 문서상 캐시 주기(12시간)를 따르고, 요청 쿼리와 무관한 공유 캐시로 함선 선택마다 원본을 다시 호출하지 않는다.
- 연결은 고유번호(UUID) 일치를 우선한다. 고유번호가 없는 UEX 항목에 한해서만 게임 원본의 영문 전체 이름과 유일하게 같은 항목을 연결하고 화면에 이름 기준임을 알린다. 서로 다른 UUID, 부분 이름, 여러 후보, 변형의 기본형 대체는 허용하지 않는다. 조회 실패·함선 미확인·판매처 없음은 서로 다른 안내다.
- 가격 제보일과 자료 조회일을 구분해 표시하며 UEX 커뮤니티 제보가 실시간 재고를 보장하지 않는다는 안내를 붙였다. 게임 내 판매 가격을 직접 실측한 것은 아니다. 로컬 검수는 UEX 공개 응답을 동일한 서버 변환 함수로 처리해 사용한다.

출처: [UEX 전체 함선 구매 가격 API](https://uexcorp.space/api/documentation/id/get_vehicles_purchases_prices_all/), [UEX 함선 API](https://uexcorp.space/api/documentation/id/get_vehicles/), [UEX 터미널 API](https://uexcorp.space/api/documentation/id/get_terminals/). 내부 브라우저에서 문서와 기존 라이브를 확인했다.

## 기존 운영진 피드백

- 한국어 화면에서 함선과 부품의 번역명 아래에 게임 영문 이름을 함께 표시한다. 선택기, 장착 카드, 교체 후보, 상세, 구매 화면에서 같은 이름을 확인할 수 있다. 종류·통계·조작 문구는 한국어를 유지한다. 내부 코드명은 영문 병기 대상이 아니다.
- 모바일의 A/B 전환은 상단 구성 전환에 모은다. 비교 화면의 중복 전환 버튼만 숨기며, 비교표와 다른 구성으로 복사하는 기능은 유지한다. 구성 작업 영역의 중복 비교 이동 버튼도 제거한다.
- 미사일과 폭탄 랙은 교체 가능한 경우 랙 카드에 `랙 교체` 버튼을 표시한다. 고정 랙은 `고정 랙 · 교체 불가`로 구별한다. 탄약 교체와 랙 교체는 각각의 부품을 대상으로 한다.
- 전원은 아이콘·켜짐/꺼짐·버튼 배경으로 상태를 표시한다. `aria-pressed=true`가 켜진 상태다. 버튼의 접근성 이름과 도움말은 다음 동작(전원 끄기/켜기)을 안내한다. 기존 계산·실행 취소를 그대로 사용한다.

## 함선 DB 대분류와 세부 역할

`ship-filter-taxonomy.json`의 `browseGroups`는 VOLT 탐색용 분류다. 공식 또는 현재 canonical 역할 값을 명시적으로 묶으며, 새로운 함선 성능·용도나 개별 함선 수기 태그를 만들지 않는다.

- 전투: 기존 전투 역할 → 요격기, 경/중/중전투기, 폭격기 등 원문 역할별 선택.
- 지원: 의료·급유·회수·수리와 원문에 Carrier가 명시된 세 역할. 건설·Industrial은 산업으로 분리한다.
- 산업: 화물·채광·인양·정제, Heavy Construction, Industrial.
- 운송·여행, 탐사·과학, 레이싱, 다목적도 유지해 기존 함선이 탐색에서 빠지지 않는다. 복합 역할은 여러 대분류에 포함될 수 있다.

대분류를 바꾸면 하위 역할 선택을 초기화한다. 규모·제조사·검색 조건은 유지한다. 대분류 `전체`에서는 기존 다중 역할 태그와 전체 역할 검색을 그대로 사용할 수 있다. 전체 필터 초기화는 새 대분류도 해제한다. 데이터와 분류 생성기, 클라이언트 매니페스트를 함께 갱신한다.

모바일에서는 대분류를 고른 뒤 해당 분류 안의 세부 역할을 검색할 수도 있다.

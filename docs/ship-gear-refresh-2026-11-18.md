# 함선 DB · 개인 장비 개선 검수

## 자료 원칙과 재생성

2026-11-18 운영자 지시에 따라 함선 성능 자료를 설치된 게임 파일로 전환했다.
과거 Erkul 스냅샷은 조사 기록으로만 남으며 현재 생성기의 입력이 아니다.
기존 동기화 미리보기 API는 관리자 인증 후 410을 반환하고 외부 요청을 하지 않는다.
기존 Safe Apply 실행 파일은 종료 안내만 한다. 기존 함선 ID와 영구 제외 8종은 유지한다.

- 게임: `Game2.dcb`, 차량 XML, 장착 파일 XML, 영어 `global.ini`
- 설치 빌드: `4.10.200.58746`, changelist `13165946` (manifest의 branch는 `sc-alpha-4.10.0`)
- DCB SHA-256: `005984f5507314a0d5dc3a8d7457bffc03578eeabb1e5da6e6c2d010e81649f4`
- 한글: 같은 설치의 `korean_(south_korea)/global.ini`; `,P` 표시가 붙은 키도 읽는다.
- 출시: RSI 공식 Ship Matrix. 성능 값은 여기서 덮어쓰지 않는다.
- 구매·대여: UEX. 함선의 게임 고유번호를 우선 대조하고, 없으면 정확한 영문 이름만 대조한다.

```powershell
npm run shipdb:sources:refresh
npm run loadout:build -- --cache-dir <게임 캐시>
npm run loadout:ko -- --ini <한국어 global.ini>
npm run shipdb:canonical:build -- --cache-dir <게임 캐시> --ko-ini <한국어 global.ini>
```

재생성은 게임 파일과 명시적 식별자 목록을 사용한다. 새 후보를 자동으로 출시 처리하지 않는다.
221개의 게임 파일 함선과 27개의 공식 사양 전용 함선으로 공개 목록은 248개다.
Galaxy와 Liberator는 공식 출시 상태를 확인하여 게임 파일 목록으로 옮겼다.
Marauder도 공식 출시를 확인했다. Hyun은 게임 파일에는 있지만 공식 목록에 없어 출시 미확인으로 표시한다.
Galaxy·Liberator의 로드아웃에는 기존 검수 이미지와 정확한 함선 ID를 연결했다.
Marauder·Hyun은 정확한 이미지가 검수되지 않아 다른 기체 사진을 대신 넣지 않는다.

화물은 기본 장착 파일의 일반 화물칸 합계다. 별도 XML을 사용하는 문·리프트 아래 장착물도 읽는다.
같은 격자가 서로 다른 슬롯에 장착되면 각각 센다. 광석 전용 저장소는 일반 화물과 합치지 않는다.
F7C Hornet Mk I의 화물칸 연결 정의는 읽지 못해 null로 남겼다(0으로 바꾸지 않음).
크기는 아이템 정의의 AttachDef.Size를 쓴다. 차량 XML의 size는 다른 필드이므로 섞지 않는다.
Constellation Aquila의 한국어 설명은 패치에 한국어로 제공되지 않아 영문 표시 안내를 붙인다.
보험 청구 시간 등 이번에 검증하여 추출하지 않은 수치는 과거 자료에서 가져오지 않는다.

## 화면

개인 장비 목록에 접을 수 있는 상세 필터와 선택한 필터 해제 단추를 추가했다.
무기는 제조사·종류·피해·발사 방식·탄창·무게, 방어구는 제조사·부위·등급·수납·온도·무게로 찾는다.
구매 가능 필터는 판매처가 확인된 변종이 하나라도 있는 묶음을 보여 준다.
가격 조회 실패·부분 실패·조회 중을 구분하며 다시 조회할 수 있다.
같은 영문 이름이 여러 변종이나 별도 게임 모드에 있으면 이름만으로 상점을 잘못 연결하지 않는다.

피격 화면은 직접 만든 인체 도형과 6개 부위 카드, 선택한 부위의 장비·피해 설명으로 구성했다.
다른 게임에서는 화면 배치만 참고했다. 체력·부위·피해 수치는 Star Citizen 자료만 사용한다.
한 발 피해와 잔여 체력 막대는 기존 가정 계산이다. 실제 기절·사망을 예측하는 값이 아니며 화면에 명시한다.
전체 체력 70과 개별 부위 체력은 별개이며 서로 합산하지 않는다.
휴대폰에서는 필터를 기본 접힘으로 두고 이름·핵심 수치·최저가를 우선 표시한다.

## 호스트 처리

`volt-ceo.pages.dev`의 모든 경로와 메서드는 동일 경로·쿼리의 `https://www.volt.ceo`로 308 이동한다.
미리보기 주소는 유지하고 `X-Robots-Tag: noindex`를 붙인다.
전체 경로를 포함하는 기존 `_routes.json`을 유지한다.
배포 게이트와 Actions에는 운영 Pages 주소를 사용하는 호출이 없었다.
실제 운영 로그인 요청에서 Discord 복귀 주소가 `https://www.volt.ceo/auth/discord/callback`인 것을 확인했다.
Discord 개발자 대시보드의 등록 목록 자체는 열어 보지 않았다.
Bot Fight Mode와 CSP는 바꾸지 않았다. 화면별 이용 통계도 추가하지 않았다.

## 검증 범위

자료는 게임 파일을 직접 읽어 확인했으며 실제 게임 안에서 측정한 값은 아니다.
UI 검수는 내부 브라우저의 데스크톱과 375px 화면에서 수행한다. 실제 휴대폰 검수와 구분한다.
자동 검사는 필터 조합·가격 실패 복구·부위 선택·새 함선 연결·호스트 처리 및 기존 전체 검사를 포함한다.
최종 전체 시험과 배포 버전은 작업 보고에서 실제 완료 결과로 기록한다.

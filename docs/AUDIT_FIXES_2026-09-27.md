## 배포와 운영

- 캐시 버전 `20260927-01`. 기존 DB 바인딩을 재사용하며 추가 외부 서비스나 비밀 설정은 필요 없다.
- `0013_atomic_security.sql`은 보안 카운터·AI 예산·Discord 세션 테이블만 추가한다. 코드에서도 동일한 CREATE IF NOT EXISTS를 수행하므로 코드가 먼저 배포되어도 작동한다. 기존 데이터 삭제/변환 없음.
- 기존 Discord 로그인 쿠키에는 서버 세션 id가 없어 배포 후 한 번 다시 로그인해야 한다. 새 로그인은 최대 7일 또는 Discord access token 유효기간까지 유지한다. 역할 확인이 5분 이상 오래되면 Discord API를 다시 조회하며, 조회 장애 때는 보호된 기능을 503으로 차단한다.
- OAuth access token은 D1에 AES-GCM 암호문으로만 저장한다. 브라우저에는 토큰을 전달하지 않는다. 로그아웃은 서버 세션을 제거한다.
- 과거 계정 소유자를 알 수 없는 `volt-hangar`/`volt-planner-state` 값은 어떤 계정에도 자동 합치지 않는다. 로그인 계정은 서버 선호도를 복구하며, 익명 작업은 별도의 guest 저장소를 쓴다. 이미 잘못 병합된 서버 데이터는 소유자가 구분해 삭제해야 한다.
- 제한은 실패한 요청도 예약한다. Discord 웹훅의 명확한 실패 응답은 예약을 되돌리지만 네트워크 오류처럼 전송 결과가 불명확한 경우 중복 전송 방지를 위해 예약을 유지한다.
- AI 기존 KV 추정 사용량은 D1 최초 초기화 때 한 번 이어받는다. 이후 일/월 예산은 D1이 결정하며 KV는 근사 통계다. 예산은 요청당 설정된 추정 비용 기준이며 공급자 실제 청구액의 보장값은 아니다. 초기 이관 이전 KV 오차는 소급 복구하지 못한다.
- 전역 로그인 거부를 제거했으므로 분산 공격에 대해서는 기존 관리자 비밀번호의 강도가 중요하다. IP별 5회/15분 제한은 유지한다. Cloudflare 보안 설정은 변경하지 않았다.

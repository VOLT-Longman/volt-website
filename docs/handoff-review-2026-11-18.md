# 2026-11-18 인계 검수

판정: Claude의 새 기능은 유지하되 아래 오류를 고쳐 배포한다. 검수 시작 당시 라이브는 `20261118-06`, main은 `2acfb34`였다. 검수 전 자동 배포를 막기 위해 진행 중이던 Smoke 실행 `44228341488`을 취소했다. 검수 대상은 채광 안내, 운송 계약, 부품 제작 탭이며 무역플래너·FPS·AI 확장은 포함하지 않는다.

## 확인한 오류와 수정

- 로드아웃 장바구니에서 장착 탭으로 돌아갈 때 고정 KPI 줄이 탭 위를 덮어 클릭을 가로챘다. overview가 없는 배치에서는 KPI의 실제 높이를 확보했다. 강제 클릭 없이 데스크톱·390px 회귀 검사로 확인한다.
- 기존 접근성 검사는 한 테스트에서 axe를 다섯 번 실행해 30초 제한에 근접했다. `test.slow()` 대신 상태별 다섯 테스트로 나눴다. 각 상태의 전체 페이지 검사, 규칙, 심각도, 빈 allowlist, 정상 제한 시간은 유지한다. 탭을 왕복하는 흐름은 별도 검사한다.
- 채광 추출기가 같은 resource의 마지막 MineableElement를 선택해 Aphorite에 Flowstone의 특성을 붙였다. 실제 암석 구성에서 참조하는 element만 사용한다. 해당 Aphorite는 저항 0, 최적 구간 위치 0.7이다. 참조 간 값이 다르거나 누락되면 단일 값을 만들지 않는다.
- 광물별 상세가 같은 암석의 첫 항목만 표시했다. Aluminum의 2.8–6.8%, 39.2–83.2%를 포함해 별도 구성 항목과 소수 함량을 보존한다. 미검증 수율 점수 정렬을 제거하고 암석 비중순으로 표시한다. 누락 값은 0으로 만들지 않는다.
- 운송 추출기의 중복 제거가 서로 다른 배송 주문을 삭제했다. `HaulCargo_SingleToMulti_Interstellar_Bulk_OrganiMass`의 Dropoff1/2/3은 각각 최소 44/44/40 SCU다. 원본 주문 식별자와 min/max를 보존한다. max=0을 확정 수량으로 취급하지 않고 상한 미확인으로 표시하며 총량을 추정하지 않는다.
- 휴대폰 운송 화면의 암묵적 grid 열이 표 너비(약 752px)까지 늘어나 등급·필터도 잘렸다. 열을 화면 안에 제한하고 표 내부만 스크롤되게 했다. 표에 키보드 접근을 제공하고 필터·등급·표 외곽의 실제 좌표도 검사한다.
- 제작에서 채광으로 이동할 때 상세와 부모 교체 창을 함께 닫고, 채광 화면을 먼저 활성화한 후 해당 광물 제목으로 초점을 옮긴다. 교체 후보에서 시작하는 경로를 검사한다.
- 제작 자료는 로드아웃과 같은 게임 빌드일 때만 붙인다. 채광 자료로 연결 가능한 재료만 이동 버튼을 표시한다. Sadaryx 등 매핑되지 않은 재료에는 위치 미확인을 표시한다.
- 광물/장소 전환 시 이전 검색을 비워 결과가 잘못 사라지지 않게 하고, 화면 재렌더링 시 필터와 상세 제목의 초점을 보존한다.

## Linux 원인 비교

[별도 진단 실행 44229266223](https://github.com/VOLT-Longman/volt-website/actions/runs/44229266223)에서 원래 다섯 axe 검사와 클릭 흐름을 각 커밋에 세 번 실행했다. 진단용 시간 계측 외 제품 코드는 각 커밋 그대로다.

CI는 잠긴 Playwright 버전의 headless shell만 설치하고 브라우저·npm 캐시를 사용한다. 3분할, 작업당 15분 제한, 배포 전 20분 게이트는 유지한다. GSAP는 원본 바이트 검사를 유지하며 `.gitattributes`로 해당 배포 파일의 LF를 고정한다. Windows 화면을 Linux 기준 이미지로 승인하지 않는다.

## HTML 및 접근 정책

`mining.js`, `hauling.js`의 한 draw 함수당 한 innerHTML 허용은 유지한다. 문자열·속성 값을 esc 처리하며 누락됐던 분류 class 값도 이스케이프했다. 악성 이름과 분류 값을 넣는 회귀 검사로 요소/속성 삽입을 막는지 확인한다. 허용 수를 추가로 늘리거나 보안 검사를 해제하지 않는다.

현재 임시 공개 상태는 유지한다. 채광·운송 화면과 데이터의 향후 회원 제한 여부는 소유자 답변 전까지 바꾸지 않는다. 제작 JSON은 기존 loadout 경로 정책을 따른다.

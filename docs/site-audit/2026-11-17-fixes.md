## 함선 변경창 압축

함선을 선택한 뒤 **변경**을 누르면 217개 카드가 제한된 목록 높이를 나눠 가지며 찌그러졌다. 자동 브라우저 재현에서 카드 높이가 PC 1280px에서 약 4.98px, 모바일 390px에서 2px까지 줄었다.

그리드의 자동 행 높이를 내용 크기로 유지하고 위에서부터 배치한다. 기존 목록 내부 스크롤을 유지한다. 회귀 검사는 두 화면 크기에서 카드 높이, 이름 잘림, 사진 16:9 비율, 스크롤 영역, 다른 함선 선택을 확인한다.

## 자료 및 배포 검사

- 함선 슬롯 정규화를 생성기에도 적용한다. 완전히 동일한 포트만 합치며, 내용이 다른 중복 포트는 생성 오류로 중단한다.
- 222개 함선 자료에 대해 포트 경로 중복과 교체 가능한 슬롯의 호환 규칙 누락을 검사한다.
- 빠른 함선 선택에서 먼저 보낸 요청의 늦은 응답이 최신 선택을 덮지 않도록 요청 순서를 확인한다.
- 배포 확인 불가를 성공으로 처리하지 않는다. 단순 HTTP 오류와 사이트가 명시한 봇 차단도 구분한다.
- 릴리스 대기 시간을 20분으로 늘린다. 통과하지 않은 검사로 배포를 승인하는 예외는 추가하지 않는다.

## 시각 기준 변경이 필요할 때

1. 화면 변경을 작업 브랜치에 올린다.
2. 같은 브랜치에서 `Visual Baseline`을 수동 실행한다. main 실행은 거부한다.
3. 해당 커밋의 `linux-visual-baselines-*` artifact를 내려받아 이미지를 검토한다.
4. 검토한 이미지를 `tests/smoke/visual-regression.spec.js-snapshots/`에 반영하고 같은 브랜치에 커밋한다.
5. 코드와 기준 이미지를 함께 검사한 뒤 main에 반영한다. 워크플로가 main을 직접 수정하지 않는다.

이번 변경에서는 기존 시각 기준 이미지와 비교 허용치를 바꾸지 않았다.

## 남은 항목 및 확인 못 함

- Discord 커뮤니티 접근 제한 코드는 선행 버전에서 반영됐다. 운영 역할 설정과 실제 멤버 로그인·역할 회수는 별도 확인이 필요하다. 이번 수정은 접근 제한을 우회하지 않는다.
- 로그인 기능의 브라우저 회귀 검사는 명시적 테스트 계정 응답을 사용한다. 실제 운영 계정 인증 검증으로 볼 수 없다.
- 실제 휴대폰, 화면 낭독기, 물리 한글 입력기는 확인 못 함.
- 게임 원본 전체 추출은 이번 환경에서 다시 실행하지 않았다. 공통 정규화 로직을 현재 JSON과 생성기에 적용하고 결과를 검사했다.
- 감사의 추가 서버 보안 항목, 남은 Erkul 의존, 계산식 실측 및 나머지 중·하 우선순위 지적은 이번 수정 범위에 포함하지 않았다.

This original Latin display typeface is created for the VOLT website. The V3
design uses a fleet-navigation system of clipped terminals and open counters.
It may be used, modified, and redistributed only with VOLT Fleet's permission.

The typeface deliberately contains a Latin display subset. Korean text is not
included and must use the website's Korean fallback font stack.

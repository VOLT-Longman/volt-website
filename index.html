VOLT란?

VOLT는 전략적 작전과 자율적 참여를 기반으로 한 한국 커뮤니티 Star Citizen 함대입니다. 물류·무역을 중심으로 전투, 정보, 커뮤니티 운영을 아우르는 통합된 체계적 구조를 갖추고 있으며, 대규모 작전에서도 충돌과 혼란을 최소화하도록 설계되었습니다.

"자율적으로 참여하되, 기준은 명확하다" — VOLT는 강압이 아닌 구조적 리더십을 통해, 구성원들이 예측 가능한 규칙 안에서 안정적으로 협업하는 환경을 추구합니다.

VOLT-무역허브란?

무역허브는 함대 내부 거래, 임무 모집, 자산 흐름 관리를 위한 운영 플랫폼입니다. 무역플래너가 개별 작전의 수익과 운송 조건을 계산하는 도구라면, 무역허브는 함대 단위의 거래와 인력 매칭을 관리하는 공간입니다.

유의사항 모든 거래는 인게임 화폐(aUEC)만 허용되며, 현금·계좌이체·실물 등 현금성 거래는 전면 금지됩니다. 시세 교란, 허위 매물, 분쟁 유발 행위 또한 금지되며, 반복 위반 시 이용 제한 조치가 적용됩니다.

VOLT Comms

함대 지휘망 PTT 무전기

Discord와 병행 사용하는 VOLT 전용 반이중 음성 통신 앱입니다. 한 번에 한 명만 송신할 수 있는 무전기 규율을 서버가 강제해, 작전 중 지휘망 혼선을 줄이고 명확한 음성 전달을 지원합니다.

PTT 무전 통신

Push-To-Talk 방식으로 필요한 순간에만 송신합니다.

반이중 중재

한 명이 발언 중일 때 다른 사용자의 송신은 거부 비프음으로 차단됩니다.

사용 방법

  1. 1
    VoltComms.exe 실행

    처음 실행하면 설정 화면이 자동으로 열립니다.

  2. 2
    접속 정보 입력

    서버 주소와 포트는 운영진에게 전달받은 값을 입력합니다. 기본 포트는 TCP 8443입니다.

  3. 3
    비밀 토큰 / 콜사인 입력

    토큰은 함대원에게만 공유되는 인증값입니다. 홈페이지에는 공개하지 않고 Discord 또는 운영진을 통해 안내합니다.

  4. 4
    PTT 키 설정

    [키 변경] 버튼을 누른 뒤 원하는 키나 마우스 버튼을 누릅니다. 게임에서 이미 사용하는 키와 겹치지 않게 설정하는 것을 권장합니다.

  5. 5
    마이크 / 스피커 선택

    입력 레벨 막대와 소리 테스트로 장치를 확인합니다.

  6. 6
    연결 확인

    저장 후 메인 화면에 "연결됨" 상태가 초록색으로 표시되면 준비 완료입니다.

운영자용 서버 정보

서버는 Go 기반 단일 바이너리로 제공됩니다. 기본 포트는 제어 TCP 8443, 음성 UDP 4001입니다. 방화벽과 보안그룹에서 두 포트를 모두 허용해야 합니다.

서버 실행 예

./volt-server -token "비밀토큰"

TLS 사용 시

./volt-server -token 비밀 -tls-cert cert.pem -tls-key key.pem
문제 해결
  • 연결이 안 되면 서버 주소와 포트(TCP 8443), 방화벽 인바운드 허용을 먼저 확인하세요.
  • 음성이 안 들리면 음성 UDP 4001 포트 개방과 마이크/스피커 장치 선택을 확인하세요.
  • PTT가 게임 안에서 동작하지 않으면 게임 내 키와 겹치지 않는 키로 다시 설정하세요.
  • 비밀 토큰과 서버 주소는 운영진에게 문의해 받은 값을 사용하세요. (보안을 위해 홈페이지에는 공개하지 않습니다.)

접속 정보가 필요하신가요?

비밀 토큰과 서버 주소는 보안을 위해 홈페이지에 공개하지 않습니다. Discord 또는 운영진을 통해 안내받으세요.
